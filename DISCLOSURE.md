## 2. Third-Party Libraries & Dependencies

### Backend Dependencies (Python)
- **FastAPI:** High-performance asynchronous web framework for building REST APIs.
- **Uvicorn:** Lightning-fast ASGI web server implementation.
- **Pydantic v2 & Pydantic-Settings:** Data validation, typing enforcement, and environment settings.
- **pypdf:** Lightweight, pure-Python PDF document parsing and passage extraction.
- **xml.etree & zipfile (Python Standard Library):** Direct parsing of Microsoft Word (.docx) OpenXML document structure and heading hierarchies.
- **SQLAlchemy 2.0 & psycopg 3:** PostgreSQL relational database engine with Row-Level Security integration, and SQLite compatibility for local testing.
- **HTTPX:** Async HTTP client used for direct REST calls to Google Gemini API (structured JSON claim verification) without heavyweight SDK overhead.
- **Pytest, pytest-asyncio & Ruff:** Testing framework, async test client, and lightning-fast linter/formatter.

### Frontend Dependencies (TypeScript / React)
- **React 18 & React DOM:** Declarative UI library.
- **Vite:** High-performance frontend build tool and development server.
- **TypeScript:** Strict type-safety across all UI components and API contracts.
- **Tailwind CSS:** Utility-first CSS framework configured with neutral enterprise design tokens.
- **Lucide React:** Clean, minimal icon set for functional UI state indicators (never decorative clutter).
- **Vitest & React Testing Library:** Unit testing framework and component interaction testing.
